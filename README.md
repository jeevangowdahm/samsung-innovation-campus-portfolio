# SIC Python Portfolio (`sic-python-portfolio`)

A comprehensive Python portfolio covering programming fundamentals, Excel automation, data analysis, and data visualization.

---

## 📌 Contents & Highlights

- **Python Fundamentals & Scripting**: Core syntax, modular arithmetic operations, user input handling, and control flows.
- **Excel Automation**: Creating and managing spreadsheets programmatically using `openpyxl` (`create_excel.py`).
- **Data Analysis with Pandas**: Loading, cleaning, and inspecting tabular datasets.
- **Data Visualization with Matplotlib**:
  - Line plots, bar charts, scatter plots, and histograms.
  - Custom styles, legends, annotations, and multi-subplot figures.
  - Exploratory analysis on real-world datasets:
    - QS World University Rankings (`qs-world-rankings-2025.csv`)
    - Titanic Passenger Data (`titanic.csv`)

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/jeevangowdahm/sic-python-portfolio.git
cd sic-python-portfolio
```

### 2. Set Up a Virtual Environment
```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install pandas matplotlib openpyxl
```

### 4. Run Scripts
```bash
# Basic arithmetic CLI
python main.py

# Excel automation
python create_excel.py

# Matplotlib visualization examples
python mat1.py
```
